YOUR VIDEOS GO HERE  (Ch.04 · the reel wall)
============================================

There are 8 PLACEHOLDER clips already in this folder:
   reel-01.mp4  ...  reel-08.mp4

EASIEST WAY (no code editing):
  Just REPLACE any of these files with your own video, and KEEP THE SAME NAME.
  e.g. delete reel-01.mp4 and drop in your own clip renamed to  reel-01.mp4
  The tile shows it as a stylised (grain + vignette) thumbnail, and it plays
  full-screen when clicked.

Tips:
  - mp4 (H.264) is the safest format for browsers.
  - Portrait clips fit the tiles best, but anything works.
  - Optional: add a still thumbnail image and it will be used instead of the
    video frame — see the poster field below.

WANT DIFFERENT FILENAMES OR A CUSTOM THUMBNAIL?
  Open  src/experience/Experience.jsx  → block marked "ADD YOUR VIDEOS HERE"
  (the REELS array). For each tile you can change:
     src    -> "/reels/whatever.mp4"   (or "" to show the plain gradient tile)
     poster -> "/reels/thumb.jpg"       (optional still image thumbnail)
